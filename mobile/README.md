# 📱 ARATEL Mobile App (Flutter)

ARATEL 초고액 자산가(VVIP) 전용 iOS / Android 모바일 애플리케이션 (Flutter).

## 🚀 주요 기능
* **자산 인증 센터**: 등기부 연동 및 VVIP 등급 관리 (Diamond ~ Bronze)
* **암호화 라운지**: 24시간 익명 소통 및 스크린샷 방지 보안 라운지
* **AI 아뜰리에**: 3D 평면도 가상 공간 가구 배치 및 프라이빗 클럽 딜
* **VIP 컨시어지**: 자산관리(TWO CHAIRS), 방역, 건강검진, 문화 구독 예약

## 🛠 실행 방법
```bash
cd mobile
flutter pub get
flutter run
```
