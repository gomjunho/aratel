# 🏛️ ARATEL (아라뜰)

> **초고액 자산가(VVIP) 전용 폐쇄형 디지털 자산 증명 및 하이엔드 라이프스타일 큐레이션 플랫폼**

---

## 📌 1. 프로젝트 개요 (Overview)

**ARATEL(아라뜰)**은 단순한 부동산 매물 탐색이나 데이터 나열 중심의 대중 프롭테크 플랫폼에서 벗어나, 검증된 하이엔드 단지 실소유주 및 자산가들에게 **'무결한 신뢰 자본'**과 **'고해상도 정보 네트워크'**를 제공하는 폐쇄형 커뮤니티 & 라이프스타일 플랫폼입니다.

대중 플랫폼(네이버 부동산, 호갱노노 등)이 가진 정보 불순물과 투기 세력에 의한 독성 파동(Toxic Wave)을 배제하고, 엄격한 게이트키핑과 양방향 암호화 기술을 바탕으로 자산 가치 방어 및 차별화된 상류층 주거 문화를 구축합니다.

---

## 🎯 2. 프로젝트 목적 (Project Objectives)

1. **무결한 자산가 식별 및 심리적 정체성(Ego) 구축**
   * 암호화된 실시간 등기부 API 및 핀테크 인증을 활용한 1분 자동 소유주 검증 체계 구현
   * 자산 규모 및 소득 증빙에 따른 VVIP 등급제(Diamond, Platinum, Gold, Bronze)를 적용하여 독점적 정체성과 심리적 안전감 부여

2. **Toxic Signal이 제거된 고해상도 정보 네트워크 형성**
   * 투기성 노이즈, 허위 매물, 비방성 리뷰를 24시간 AI 및 운영 정화 시스템으로 차단
   * 실실소유주 간의 정밀한 주거 경험, 재건축/단지 현안, 절세 및 고급 투자 노하우 공유

3. **인증-소통-소비 가치 사슬의 선순환 생태계 조성**
   * 단지 커뮤니티 활동 및 유익 정보 공유를 통해 획득한 포인트(Aratel Point)를 수입 브랜드 '클럽 딜' 및 VIP 컨시어지 서비스와 연동하여 압도적인 사용자 락인(Lock-in) 창출

## 💎 3. 핵심 가치 사슬 (3 Value Chains)

```
[ 인증 (Verification) ] ➔ [ 소통 (Communication) ] ➔ [ 소비 (Consumption) ]
  • 1분 등기 API 연동        • 단지별 디지털 웰컴 홈      • AI 아뜰리에 (3D 인테리어)
  • VVIP 등급 산정 게이트키핑   • 암호화 익명 라운지         • 수입 브랜드 프라이빗 클럽 딜
  • 권한 위임 (가족/관리인)    • 스마트홈 & AI 에이전트      • VIP 컨시어지 & 웰니스
```

### 1) 🔐 인증 (Verification)
* **Trust API Sync**: 휴대폰 본인확인 + 암호화 등기부 API 실시간 연동 (1분 자동 인증)
* **VVIP Tiering Governance**: 소득금액증명원, 잔고증명서, 등기완료통지서 증빙을 통한 다이아몬드/플래티넘 등급 산정
* **보안 환경**: 개인정보 마스킹 및 화면 캡처 방지(Screen Capture Prevention)로 정보 유출 원천 차단

### 2) 💬 소통 (Communication)
* **디지털 웰컴 홈**: 조경 스토리 및 아트 도슨트, 스카이라운지/피트니스 실시간 혼잡도 대시보드
* **스마트 제어 & AI 에이전트**: 자연어 기반 생활 요청 처리 ("조식 예약해줘", "사우나 혼잡도 확인해줘")
* **양방향 암호화 익명 라운지**: 익명 닉네임 + 실소유 뱃지/단지명 조합으로 발언의 무게감 보장 (유출 시 즉시 영구 제명)
* **Trust Score & 리워드**: 절세/투자 정보 유효성 검증 시 아라뜰 포인트 지급 및 Diamond 등급 피드 상단 가중치 부여

### 3) 🛍️ 소비 (Consumption)
* **AI 아뜰리에 (3D Virtual Interior)**: 아파트 평면도 기반 명품 리빙 브랜드(B&B Italia 등) 가구 가상 배치 및 실재고 연동
* **클럽 딜 (Club Deal)**: AI 아뜰리에 시뮬레이션 기반 단지/등급별 VVIP 한정 수입 가구·가전 프라이빗 공동 오더
* **VIP 컨시어지**: 우리은행 TWO CHAIRS 자산관리, 하이엔드 주거 방역, VIP 건강검진, 그림 구독 서비스 통합 reservation

## 🏗️ 4. 서비스 정보 구조 (IA: Information Architecture)

* **홈 (Welcome Home)**: 마이홈(스마트홈/AI 에이전트), 라이프(조식·커뮤니티 예약/아트 도슨트), 인사이트(실거래 산점도/공급 물량 분석)
* **커뮤니티 (Verified Lounge)**: 단지 라운지(실소유주 익명 게시판), VIP 라운지(Diamond/Platinum 전용 고급 투자/절세 라운지)
* **AI 아뜰리에 (Space Design)**: 3D 가상 공간 시뮬레이션, AI 홈스타일링 큐레이션
* **컨시어지 (VIP Service)**: 금융(TWO CHAIRS), 생활(럭셔리 방역/건강검진/그림 구독), 클럽 딜
* **마이페이지 (Digital Identity)**: 자산 인증 센터, 멤버십 등급 관리, 포인트 및 뱃지
